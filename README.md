# 学员交付管理系统（演示版）

面向 1v1 学员交付场景的业务系统：**按产品配置交付模板 → 为每个学员自动生成交付任务清单 →
每一次交付动作全程留痕可追溯**；并打通内容库、社媒账号台账、微信小店订单与飞书文档同步。

> **在线演示**：<http://82.156.149.226:3001/> · 演示账号 `admin` / `admin123`
>
> ⚠️ 本仓库内的数据库是**脱敏生成的演示数据**，真实业务数据、密钥与客户内容均已剔除。
> 详细的脱敏范围见文末「数据与隐私说明」。

---

## 技术栈

| 层 | 选型 |
|---|---|
| 框架 | **Next.js 16**（App Router）+ **React 19** + TypeScript |
| 数据库 | **SQLite**（better-sqlite3，不引 ORM，直接写 SQL） |
| 样式 | Tailwind CSS 4 |
| 鉴权 | HMAC 签名 Cookie；中间件在 **Edge Runtime** 用 Web Crypto 复刻 Node 端签名算法（Node 的 `crypto` 在中间件里加载不了） |
| 其他 | xlsx（导入导出）、Playwright（抖音采集脚本）、sharp（图片处理） |

## 主要功能

| 模块 | 说明 |
|---|---|
| 学员（IP）管理 | 档案、分类标签、合作类型与服务档位、阶段进度、飞书文档挂载 |
| 交付模板 | 按产品类型配置阶段与任务清单，支持必填项、默认负责人、到期偏移天数 |
| 交付任务 | 按模板为每个学员生成任务；状态流转、完成记录、附件、完成备注 |
| 交付日志 | 状态变更 / 编辑 / 上传等动作全部留痕，可追溯到操作人 |
| 内容库 | 素材转写、选题文案、改写稿与平台数据（点赞、评论、转发） |
| 微信小店订单 | 订单同步、CSV / 粘贴导入、与企微客户绑定匹配 |
| 社媒账号台账 | 各平台账号、粉丝数、备注 |
| 素材库 | 截图 / 视频，带敏感标记与回收站（软删除 + 保留期） |
| 系统设置 | 上传上限、会话时长、回收站保留期、自动备份与保留天数 |
| 用户与权限 | 角色区分（super_admin / admin）、操作日志 |

## 本地运行

```bash
npm install
cp .env.example .env      # 必填：会话签名密钥
npm run dev               # http://localhost:3000
```

首次启动会自动建表并写入种子数据，默认管理员为 `admin` / `admin123`。

生产模式：

```bash
npm run build
npm start                 # 默认监听 0.0.0.0:3000
```

## 部署形态

线上演示跑在一台 **2 核 2G 的 Ubuntu 轻量服务器**上，与另一个静态作品集站点共用同一台机器：

```
nginx :3001  ──反代──>  Next.js 常驻进程（systemd，只监听 127.0.0.1:3000）
nginx :8080  ──静态──>  作品集门户 + 数字人项目展示页
```

- 应用进程由 **systemd** 托管（`Restart=on-failure`，开机自启），**只监听回环地址**，不直接对外暴露端口。
- `SESSION_SECRET` 通过 `.env` 注入（systemd `EnvironmentFile`），不写进代码。
- SQLite 单机单用户场景足够；数据目录与应用目录同级，便于整目录备份。

## 数据与隐私说明

仓库内的 `data/app.db` 与 `data/uploads/` 是**脱敏生成的演示数据**：

- 保留了 31 个学员、209 个订单、562 条交付任务等记录的**原有表结构与关联关系**，
  因此界面上的列表、筛选、统计、任务流转都和有真实数据时一样；
- 但**姓名、手机号、身份证号、银行账号、联系地址、企业微信 / 飞书 / 微信小店的密钥与 Token、
  客户口播文案原文**等，全部替换为程序生成的假值；
- 脱敏脚本采用「**白名单式**」策略：只保留结构、外键、枚举与度量字段，其余列一律替换；
  生成后还会做三重校验（非保留列与原库零交集、保留列的格式扫描、真实姓名与中文人名语境扫描）。

此外：

- 代码里原本硬编码的飞书文档 Token、企微 / 微信小店回调 Token 与 EncodingAESKey 已替换为演示值；
- 数据库初始化脚本中的种子数据（含真实称呼）也已替换为中性文案；
- 一批按客户名命名的**一次性数据准备脚本**（xlsx 生成、飞书批量推送等）不包含在本仓库中；
- `.env`、上传素材目录、备份目录均在 `.gitignore` 中排除。

## 目录结构（节选）

```
src/
├─ app/                    页面与 API 路由（App Router）
│  ├─ api/                 接口：学员、交付、内容、订单、鉴权、飞书 / 企微回调…
│  ├─ ips/                 学员列表与详情
│  ├─ products/            产品与交付模板
│  ├─ wechat-orders/       微信小店订单
│  ├─ settings/ users/     设置与用户管理
│  └─ login/ register/     登录与注册
├─ components/             按领域拆分的组件（ip / dashboard / log / screenshot / video…）
├─ lib/                    数据访问与业务逻辑（db / auth / session / permissions / feishu / wecom…）
└─ middleware.ts           Edge 中间件：会话校验与路由保护
data/                      SQLite 数据库与上传素材（演示数据）
scripts/                   运维与数据脚本
```
